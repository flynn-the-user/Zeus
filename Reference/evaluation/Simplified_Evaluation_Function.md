# Simplified Evaluation Function

A minimal, fully-specified evaluation made of two additive terms: material
(piece values) and piece-square tables (positional bonus/penalty per square,
per piece type, per game phase).

## Piece values (centipawns)

```
P = 100
N = 320
B = 330
R = 500
Q = 900
K = 20000
```

Documented relationships these values are designed to satisfy:
`B > N > 3P`, `B + N = R + 1.5P`, `Q + P = 2R`.

## Piece-square tables

Given from White's perspective, index 0 = a8 (top-left) in the printed
layout, row-major, 8 values per rank, ranks printed top (rank 8) to bottom
(rank 1). Black uses the vertically mirrored table.

Endgame-begins condition given on the page: both sides have no queens, or
every side that still has a queen has no other piece or at most one minor
piece.

## Zeus usage

v0.1 uses only the piece-value table above (material-only evaluation); the
piece-square tables are reserved for a later, separately-measured roadmap
stage ("PST evaluation") so the Elo contribution of positional terms can be
isolated from the search-algorithm Elo gains. See `ROADMAP.md`.
